# Puck Powerups
Adds server-authoritative powerups with client-side controls, HUD feedback, icons, and effects. Install the mod on the server and on each client that should use the powerup UI and controls.

Press **F** to activate a ready powerup. The HUD shows the current powerup, its unique icon, active time, and cooldown countdown. The normal quick-chat options are no longer replaced.

<b>Magnet</b>: Puck is magnetized towards your stick if it's close enough<br/>
<b>Rage</b>: Knocks down anyone you touch for 7 seconds<br/>
<b>Grapple</b>: Launches you towards the puck<br/>
<b>Glue</b>: Puck attaches to your stick for 2 seconds<br/>
<b>Kick</b>: Knocks over the nearest player on the other team<br/>
<b>Tornado</b>: Flings everyone near you around
<b>Jetpack</b>: Launches you updwards uncontrollably (this one is pretty useless)
<b>Turbo</b>: Sprinting becomes much faster
## Installation 
Download and unzip the latest [release](https://github.com/wenright/Puck_Powerups/releases) into the server's and each participating client's `Puck/Plugins` folder.

You may also want to install the [motd](https://github.com/NAsejevs/GAFURIXCustomMOTD) mod and mention the **F** binding for new players. You can copy the sample motd [here](https://github.com/wenright/Puck_Powerups/blob/main/motd.txt).
